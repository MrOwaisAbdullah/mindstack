# Credits

This project is a personal fork of **BrainOutside** by Hasan Aboul Hasan
— https://github.com/hassancs91/brainoutside (MIT). Git history was
stripped when this fork began; this file is the record of that lineage.

BrainOutside itself states its own origin as growing out of Andrej
Karpathy's `llm-wiki`:
https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f

BrainOutside also grew out of Hasan's MCP API boilerplate
(https://learnwithhasan.com/boilerplates/mcp-api-boilerplate/), which is
why the vendored `apps/core` registry carries some generality (endpoint
versioning, deprecation headers) this brain doesn't currently exercise.

No files are unattributed; if you find something that should be credited
here and isn't, open an issue.
