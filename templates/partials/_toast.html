{% load i18n %} {% comment %} toast notification stack. Server triggers a toast by sending the response header: HX-Trigger: {"show-toast": {"variant": "success", "message": "Saved!"}} HTMX dispatches a `show-toast` CustomEvent on the document with the payload in `event.detail.value`. Alpine root catches it, pushes onto a stack, auto-dismisses after 4s. Variants: success / error / warning / info (default). Mount once near the bottom of (the layout templates do this). {% endcomment %}
