{% comment %} Cookie-consent banner — only shown when analytics is configured AND the visitor hasn't decided yet. Gate: `GOOGLE_ANALYTICS_ID` is set (else there's nothing to consent to) and the `analytics_consent` cookie is absent (neither "granted" nor "denied"). Once the visitor clicks a button the cookie is written for 180 days, so the banner doesn't reappear on subsequent visits. Flow: - Accept → write `analytics_consent=granted`, then reload. On reload templates/partials/_analytics.html sees the cookie and loads gtag.js. - Decline → write `analytics_consent=denied`, hide the banner. gtag.js never loads. The cookie is set client-side (document.cookie) via the nonce'd helper below so it stays CSP-compliant; `Secure` is added only over HTTPS so the flow still works on the plain-HTTP dev server.
