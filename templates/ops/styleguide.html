Every component is rendered TWICE — once in the ambient theme and once inside a `.dark` container. `.dark` is a class selector in tokens.css, so putting it on a wrapper re-points the semantic variables for that subtree only; components pick the new values up automatically because they style against tokens rather than literals. That is the whole architecture, demonstrated: if a component hardcodes a colour, its dark copy is visibly wrong on this page and nowhere else. RULE FOR THIS FILE: no inline style attributes, ever. It is the reference for how the other templates look after M5.6.2, and the enforced CSP drops inline style attributes anyway.
